# Lake Garda Extension — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the trip-planning site with Phase II (Lake Garda, Jul 20–27, 2026) — schema changes, an Activities catalog of 24 entries, navigation rewire, and home/map/more integration — while leaving Phase I (Dolomites) untouched.

**Architecture:** New `activities` Zod content collection (data type, YAML files) populated by extending `scripts/migrate-itinerary.mjs` with an `emitActivities()` function. New `/activities` index + detail pages following the existing vintage poster aesthetic. Bottom nav swaps Checklist for Activities; Checklist remains reachable via `/more`. Map page extended with an activity pin layer + toggle. Home page and `/more` get phase-aware sections (PARTE I / PARTE II) without disturbing Phase I content.

**Tech Stack:** Astro 5 (`astro:content`), Zod, TypeScript strict, Tailwind v4 globals, maplibre-gl (React island), js-yaml, sharp icons, Cloudflare Workers Builds, service worker (`public/sw.js`) with cache key versioning.

**Verification model:** This codebase has no automated test suite. Each task verifies via `npm run build` (Astro runs Zod validation + TypeScript check during build), `npm run dev` smoke-test of the affected page in a browser, and (for Phase 5) a Lighthouse pass.

export default function MapView({ pins }: { pins: Pin[] }) {
  const containerRef = useRef<HTMLDivElement>(null);
  const mapRef = useRef<maplibregl.Map | null>(null);
  const markersRef = useRef<maplibregl.Marker[]>([]);
  const [showHikes, setShowHikes] = useState(true);
  const [showActivities, setShowActivities] = useState(true);

  // Init map once
  useEffect(() => {
    if (!containerRef.current) return;
    const lats = pins.map((p) => p.lat);
    const lons = pins.map((p) => p.lon);
    const bounds: [[number, number], [number, number]] = [
      [Math.min(...lons) - 0.05, Math.min(...lats) - 0.05],
      [Math.max(...lons) + 0.05, Math.max(...lats) + 0.05],
    ];

    const map = new maplibregl.Map({
      container: containerRef.current,
      style: {
        version: 8,
        sources: {
          osm: {
            type: 'raster',
            tiles: ['https://tile.openstreetmap.org/{z}/{x}/{y}.png'],
            tileSize: 256,
            attribution: '© OpenStreetMap contributors',
          },
        },
        layers: [{ id: 'osm', type: 'raster', source: 'osm' }],
      },
      bounds,
      fitBoundsOptions: { padding: 30 },
    });

    map.addControl(new maplibregl.NavigationControl({ showCompass: false }), 'top-right');
    mapRef.current = map;

    return () => {
      map.remove();
      mapRef.current = null;
    };

    const map = mapRef.current;
    if (!map) return;

        .setPopup(new maplibregl.Popup({ offset: 12 }).setHTML(popupHtml))
        .addTo(map);
      markersRef.current.push(marker);
    }
  }, [pins, showHikes, showActivities]);
